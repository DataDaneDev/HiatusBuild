# Electrical Closet Physical Mockup References — 2026-05-13

Physical reference photos for the Hiatus camper electrical closet / battery-bank bench mockup.

These are build-reference photos, not final fabrication drawings. They document the current cardboard layout, battery placement, window/ceiling context, and several tape-measure checks so the project folder has the raw physical evidence alongside the generated concept renders.

## Design context captured

- Cardboard represents the proposed electrical closet / utility cabinet mass.
- Under-window cardboard section tests the protruding tabletop / charging-platform idea.
- Battery placement photos document the real footprint and adjacency to the right-side battery-bank bench/storage zone.
- Tape-measure photos capture approximate width, depth, vertical clearance, and window-bottom references.

## Notes / caveats

- Measurements should be re-read from the original photos before making cut decisions; perspective distortion and tape angle can mislead.
- Keep the actual design gated on a final dry-fit with real component envelopes, especially battery service access, heater/fuel separation, ventilation, AC/DC separation, and removable panels.
- Use these with the generated concept folder next door: `../electrical-closet-concepts-2026-05-13/`.
